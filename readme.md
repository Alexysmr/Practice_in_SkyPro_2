# Homework. Lesson topic - "Class"

**Описание:** Курс "Объектно-ориентированное программирование" университета Sky Pro по специальности "Разработчик-Python"

**Инструкция по установке**

Для пользователя:

`poetry install --no-dev`

Для разработчика:

`poetry install`

**Зависимости:**

python 3.13.1
pytest 8.3.4

**Запуск программы:**

`python main.py`
